POK
---

Loads a .pok file which lets you apply various trainers to a game. .pok files must be smaller than 16384 bytes in length and only the first 128 'trainers' inside the file will be listed. The plugin doesn't remember which trainers you selected last time, so it will always startup with every trainer set to 'Not Set'. Selecting an entry cycles the state between 'Not Set', 'On' and 'Off'. If an entry is set to 'Not Set' it is skipped. If it is 'On', the on value from the .pok file is used. If it is 'Off' then the off value is used, so long as a value is specified. The '<<<' and '>>>' texts bottom line of the window indicate whether you can move to the previous or next page of pokes.

.pok files tend to set the off value to 0, so to stop the game getting corrupted, 0 off values are not applied. .pok files can only be opened from inside the NMI browser.

Browser Up / Down Navigation Keys: Move selection
Browser Left: Move back 8 pokes
Browser Right: Move forward 8 pokes
Space: Toggle trainer not set / on / off
Enter: Exit with selected trainers applied
Break: Cancel / Exit


PZX
---

Requires a ZX-UNO to work. Loads and starts a .pzx tape file. Hold down shift (or the tab key if this doesn't work for you) to attach the PZX file without autostarting it.


SCL
---

Converts an .SCL disk image into a trimmed .TRD file. The converted .TRD file is then autostarted. The converted filename of the .TRD file will be the 8.3 filename of the .SCL file with a .TRD extension (GAME.SCL -> GAME.TRD). If you hold down SHIFT when you select the file, it won't be autostarted after conversion.

On esxDOS 0.8.9 or higher, this will directly autostart the .SCL disk image without having to convert the file to a TRD disk image.


SCR
---

- Enable Slideshow: On / Off
- Slideshow Timer Delay (seconds): 1-60

TRD
---

Autostarts a .trd disk image file. If the disk doesn't contain a 'boot    B', the browser will automatically create a TAP file which loads and runs the first BASIC (B) file it finds in the disk image. If you hold down SHIFT when you select the file the disk image is mounted and the browser switches to TR-DOS without autostarting the disk (requires /BIN/BPLUGINS/TRD.TAP).


ROM
---

Loads and starts a 16k (16384 bytes) ROM file. Uses velesoft's .ownrom code to load the file into the divMMC memory and replace the real ROM contents. NMI is disabled until a hard reset - which also clears out the loaded ROM. Not all ROM images work correctly.


ART
IPH
---

Loads a hires (320 x 200 x 16 colours) C64 screen in Art Studio or Interpaint format. Needs ULAPlus to show the correct Commodore 64 colours. Image can be scrolled as the Spectrum screen is only 256 x 192 pixels. File must be 9002/9003 bytes long. Plugin supports the following keys:

Browser Left: Show previous screen
Browser Right: Show next screen
Browser Up: Show first screen
Browser Down: Show last screen
1: Scroll screen up a line
2: Scroll screen down a line
3: Scroll screen character to the left
4: Scroll screen character to the right
Break: Exit viewer

--

Plays AY chip and beeper .ay files. Currently supports the EMUL .ay file type. Be aware that some beeper .ay files play until they stop (Sabre Wulf) or can't be stopped once started (The Great Escape) and need a reset.

ULA
---

Applies a 176 byte ULAplus palette tap file or a raw 64 byte palette file. These can be used to recolour existing Spectrum games.

You can also create a container file with a .ULA extension. This is a text file with the following layout:

ULA!
PALETTE=ULAPLU~1/NINJAJAR.ULA
GAME=NINJAJ~1.TAP

This lets you specify a game and a colour palette using the 8.3 style filenames / path. When you select this file, it will automatically apply the ULAplus palette file specified by the PALETTE line and run the file in the GAME line.


RAD
---

Requires a ZX-UNO to work. Displays a 'raw' 6160 byte image or a 16 colour BMP file (128 x 96 pixels, 6262 bytes) using the Radastan graphics format. You can create compatible bitmaps in a package like GIMP by resizing images to 128 x 96 pixels, reducing to 16 colours and saving as a BMP without colourspace information.

Browser Right: Show next screen
Browser Up: Show first screen
Browser Down: Show last screen
